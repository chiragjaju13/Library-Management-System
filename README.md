# Library Management System (Java)

## 📚 Project Overview

The **Library Management System** is a Java-based console application developed using proper **Java package structuring** and object-oriented principles. It helps manage core library operations such as adding books, issuing and returning books, and searching records efficiently.

This project is suitable for **academic submission**, **Java practice**, and **portfolio demonstration**.

---

## 🚀 Features

- Add new books
- Update quantity of existing books
- Search books by:
    - Book ID
    - Book Name
    - Author Name
- Issue books to students
- Return books
- View all books
- View issued books
- Menu-driven console interface

## ▶️ How to Run the Project

### Prerequisites
- Java JDK 8 or higher
- Any Java IDE (IntelliJ IDEA / Eclipse / VS Code)

### Steps

1. Compile the project:
```bash
javac src/college/Library.java
```

2. Run the application:
```bash
java src.college.Library
```
